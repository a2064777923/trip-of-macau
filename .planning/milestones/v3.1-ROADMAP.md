# Milestone v3.1: Material Production and Mini-program Experience Acceptance

**Status:** Shipped 2026-05-04 with accepted UAT caveat  
**Phases:** 36-40  
**Total Plans:** 18  
**Milestone:** Material Production and Mini-program Experience Acceptance

## Overview

v3.1 promoted the planned `東西方文明的戰火與共生` material package into generated and COS-backed assets, added operator QA/reuse controls, aligned public story runtime DTOs with generated assets and safe fallbacks, connected the mini-program story-mode baseline to the live public backend, and closed the milestone with repeatable smoke evidence plus an explicit WeChat DevTools/device UAT checklist.

This milestone does not claim completion of the full gameplay engine. AR recognition, speech-input NPC interactions, route-coverage games, puzzle/cannon-defense minigames, and production-grade indoor visual positioning remain future scope.

## Milestone Summary

**Key Decisions:**

- Generated story materials are first-class material-package versions with provenance, QA status, COS-backed assets, and rollback history.
- Public runtime exposes compiled traveler-safe DTOs, not raw admin provenance, prompt text, provider payloads, or local paths.
- Mini-program acceptance for v3.1 is baseline story-mode consumption and event reporting; full gameplay engines remain explicit future scope.
- Live provider/COS mutation checks remain opt-in because they incur external cost and change persistent assets.
- WeChat DevTools/device UAT is documented but not falsely marked passed without operator execution.

**Issues Resolved:**

- The Phase 33 planned manifest now has generated/imported image, board-slice, audio, video, and package-version evidence.
- Public runtime now exposes media availability/fallback state for generated assets and validates safe field shape.
- Mini-program story mode no longer depends on mock-only story data for the flagship route baseline.
- Admin AI observability now shows cost/job/request history while scoping non-super-admin visibility.

**Issues Deferred:**

- Manual WeChat DevTools/device UAT rows remain pending in `40-UAT.md`.
- Full AR/photo recognition, speech-input NPC interactions, route-coverage minigames, puzzle/cannon-defense engines, and indoor visual positioning remain future gameplay scope.
- Full approval workflow beyond direct lifecycle controls remains future scope.
- `.lottie` package upload, sprite sheets, and sequence-frame animation pipelines remain future scope.

**Technical Debt / Caveats:**

- The mini-program story page still emits a bundle-size warning around `pages/story/index.js`.
- Local quick smoke skips live provider/COS mutation by default and relies on Phase 36 live evidence for asset production proof.
- Phase 40 verification is intentionally partial because human device UAT was not executed.
- Some older seeded storylines remain incomplete or legacy, while the flagship `east_west_war_and_coexistence` / `東西方文明的戰火與共生` runtime is the v3.1 acceptance target.
