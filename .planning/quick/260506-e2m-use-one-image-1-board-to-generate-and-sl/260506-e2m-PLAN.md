# Quick Task 260506-e2m: Use One Image-1 Board To Generate POI Map Icons

**Date:** 2026-05-06
**Status:** Executed

## Goal

Generate multiple 2.5D cartoon POI map icons from one `image-1` sprite board, slice them into transparent PNG marker assets, upload them through the backend media pipeline, and bind them to the Macau flagship POIs without introducing mini-program fallback content.

## Tasks

1. Reuse the existing generated board when present and slice it into five transparent 512x512 PNG icons.
2. Upload the icons through the admin backend asset upload API so they are persisted in `content_assets` and Tencent COS.
3. Bind the new icon asset IDs to `ama_temple`, `lilau_square`, `dom_pedro_v_theatre`, `monte_fort`, and `senado_square`, then update the replayable local SQL migration.

## Verification

- Pixel-check transparent corners and non-full alpha bounds for all five PNGs.
- Verify COS returns HTTP 200 `image/png` for all uploaded URLs.
- Verify public POI API returns GCJ-02 display coordinates and the new PNG `mapIconUrl` values.
