<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| StoryPage -> local storage route context | Story runtime chapter/anchor data is stored temporarily for tab handoff. |
| local storage/route params -> MapPage | Stored context and params can be stale, malformed, or tampered with. |
| runtime anchors -> POI resolver | Anchor ids/codes are admin-configured runtime data and must be validated before use. |
| story route UI -> permanent game state | Temporary route emphasis must not mutate permanent progress/reward/check-in data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T39-12 | Tampering | `getStoryModeRouteContext` | mitigate | Validate positive finite ids, catch malformed storage, and return `null` for invalid context. |
| T39-13 | Spoofing | map handoff route params | mitigate | Use stored route context as primary handoff and encode/sanitize story/chapter ids when navigating back. |
| T39-14 | Information Disclosure | route context storage | mitigate | Store only public ids/codes/titles/status labels; no tokens, secrets, local paths, prompts, or admin provenance. |
| T39-15 | Denial of Service | anchor resolution | mitigate | Fall back to route strip/no-geometry copy when destination cannot resolve; do not crash. |
| T39-16 | Tampering | route exit | mitigate | Clearing route context removes only temporary route emphasis and does not mutate check-ins, rewards, pickups, or exploration progress. |
</threat_model>
