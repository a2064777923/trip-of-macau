<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| public runtime API -> mini-program client | Anonymous users receive runtime DTOs and media metadata from the public backend. |
| runtime payload -> React/Taro renderers | Backend strings, media URLs, ids, and availability values are untrusted and must be typed/fallback-safe. |
| remote media URL -> WeChat media/Lottie components | Network JSON/audio/video/image can fail or be unavailable at runtime. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T39-01 | Information Disclosure | `PublicStoryMediaAssetDto`, `StoryMediaAssetItem` | mitigate | Only add Phase 38 public-safe fields and explicitly avoid prompt/script/local path/COS key/provider/cost/QA fields. |
| T39-02 | Denial of Service | `StoryContentBlockRenderer` | mitigate | Treat missing/unsupported media as visible fallback cards instead of throwing or rendering blank components. |
| T39-03 | Tampering | media availability/runtime kind fields | mitigate | Treat DTO fields as display hints only; do not grant rewards or mark progress from media availability. |
| T39-04 | Information Disclosure | `LottieAssetPlayer` error logging | mitigate | Log generic initialization failure and do not print URLs, local paths, tokens, secrets, prompt text, or provider data. |
| T39-05 | Repudiation | media completion callbacks | mitigate | Emit completion callbacks only from actual audio/video ended events; Plan 39-02 will attach idempotent event ids. |
</threat_model>
