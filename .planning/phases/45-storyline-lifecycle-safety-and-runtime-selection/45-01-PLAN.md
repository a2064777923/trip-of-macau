<threat_model>
## Threat Model

**Assets:** public story catalog, story runtime flows, chapter/content/asset references, exploration progress, user storyline sessions, reward/title/collectible bindings, admin operator trust.

**Threats:**
- **T45-01-A High: orphaned runtime data from hard delete** - Current delete removes only `storylines`, leaving chapters, flows, relation links, exploration elements, sessions, and material references behind. Mitigation: block hard delete when dependencies exist and default to archive/unpublish.
- **T45-01-B High: wrong traveler story selected** - Old duplicate is `published` and sorted first, while the mini-program treats both old and new codes as flagship. Mitigation: archive old duplicate and prefer only `east_west_war_and_coexistence`.
- **T45-01-C Medium: generic server failure for stale IDs** - Stale route IDs can surface generic "server down" UX. Mitigation: map public 404/archived story responses to controlled traveler copy and reload the current story list.
- **T45-01-D Medium: accidental deletion of played content** - Operators may confirm delete without seeing user-session impact. Mitigation: impact modal shows dependency counts and disables hard delete unless eligible.
</threat_model>
