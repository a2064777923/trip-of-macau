<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser -> QA API | UI sends QA state mutations and replacement asset ids |
| preview components -> public/COS URLs | Browser loads media previews that may fail or be unavailable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T37-06 | Tampering | QA action forms | mitigate | Require operator notes and explicit confirmation before reject/approve/replace actions. |
| T37-07 | Information Disclosure | admin QA drawer | mitigate | Keep provenance details inside protected admin routes and do not copy them into public DTO code. |
| T37-08 | Denial of Service | media preview rendering | mitigate | Use metadata preload, stable failed states, and avoid uncontrolled reload loops. |
| T37-09 | Spoofing | replacement asset selection | mitigate | Replace by `content_assets.id` from backend search results, not arbitrary URL text. |
</threat_model>
