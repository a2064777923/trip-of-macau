## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T37-10 | Information Disclosure | content asset reuse metadata | mitigate | Expose package/item context only on authenticated admin APIs, not public runtime APIs. |
| T37-11 | Tampering | downstream reuse | mitigate | Bind by existing `content_assets.id`; do not copy or mutate binaries during reuse. |
| T37-12 | Repudiation | smoke/action evidence | mitigate | Record smoke results and QA action outcomes in `37-VERIFICATION.md`. |
| T37-13 | Information Disclosure | smoke credentials | mitigate | Read bearer token from environment only and never write it to logs or tracked files. |
</threat_model>
