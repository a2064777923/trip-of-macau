<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local workstation tooling -> admin backend | Local scripts can trigger real provider work, uploads, and status transitions against live package items |
| local filesystem -> import endpoint | Generated files, slice configs, and prompt/script-derived metadata are untrusted inputs until validated and mapped to manifest-safe paths |
| OpenAI/admin AI -> package versions | External tool outputs must preserve lineage, cost, and exact manifest mapping before publish |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T36-06 | Information Disclosure | secrets exposure in local production scripts | mitigate | Read secrets from env vars or admin runtime only; never embed provider keys, COS secrets, or Chinese prompt text directly in PowerShell literals. |
| T36-07 | Tampering | path/object-key tampering in local outputs and imports | mitigate | Route all outputs through manifest-mapped relative paths and Phase 36 backend path guards before upload/import. |
| T36-08 | Elevation of Privilege | unauthorized publish/rollback through batch production flow | mitigate | Preflight must emit `requiresSuperAdminConfirmation` and live production/import commands must pass explicit confirmation flags rather than silently exceeding cost ceilings. |
| T36-09 | Information Disclosure | untrusted provider URLs/downloads in narration handling | mitigate | Use the backend bind/import endpoints so `AiOutboundUrlGuard` and backend validation stay authoritative instead of trusting raw local URLs. |
| T36-10 | Repudiation | lineage loss for slices, narration, and reward-cue branches | mitigate | Every slice/audio import must include parent/version metadata, script provenance, and manifest item keys so rollback evidence survives later replacements. |
</threat_model>
