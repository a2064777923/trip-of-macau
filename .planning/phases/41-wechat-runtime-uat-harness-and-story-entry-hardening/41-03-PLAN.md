<objective>
Document and verify the local/devtools/experience story-runtime acceptance path so future execution can truthfully distinguish automated smoke, WeChat DevTools launch, manual device UAT, and deferred full gameplay scope.
</objective>

<threat_model>
## Threat Model

**Assets:** UAT evidence, environment configuration, operator credentials, local machine paths, story runtime URLs.

**Threats:**
- **Medium: unsafe documentation of secrets** - docs and verification files must mention env var names but not real secret values or tokens.
- **Medium: operational misconfiguration** - confusing local/devtools/experience instructions could point a tester at `127.0.0.1` from a physical device and create false failures. The doc must explain LAN/tunnel requirement for physical devices.
- **Low: false closure** - manual UAT checklist must not be marked complete unless actually executed.
</threat_model>
