<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| public runtime API -> traveler client | Anonymous users can read runtime story/media payloads. |
| public backend -> material package tables | Backend reads admin-authored material production rows but must sanitize them before response. |
| content asset metadata -> public DTO | Stored asset metadata may contain internal storage fields that should not be emitted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T38-01 | Information Disclosure | `StoryMediaAssetResponse` and usage hints | mitigate | Public DTO includes only id/kind/url/mime/dimensions/fallback/usage fields and excludes prompts, scripts, local paths, provider data, costs, QA notes, and raw provenance. |
| T38-02 | Tampering | Material package table access | mitigate | Add read-only public entities/mappers and no public controller/write path for material package rows. |
| T38-03 | Denial of Service | Fallback resolution | mitigate | Resolve fallbacks from already-loaded published asset maps and database lookups; do not perform request-time external URL probing. |
| T38-04 | Spoofing | Asset availability | mitigate | Treat assets as available only when stored status is `published` and delivery URL is non-blank. |
| T38-05 | Information Disclosure | Rejected/unpublished versions | mitigate | Do not expose usage hints for rejected/draft/retry/manual-import items or non-published material versions. |
</threat_model>
