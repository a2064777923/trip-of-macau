<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| mini-program -> public event endpoints | Authenticated traveler clients report stateful story events. |
| public event endpoint -> exploration tables | Accepted events can affect progress and session state. |
| client payload JSON -> database | Arbitrary client JSON enters persisted event payloads unless validated. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T38-06 | Spoofing | Event writes | mitigate | Keep `ExperienceController.requireUserId` bearer-token gate for stateful endpoints. |
| T38-07 | Tampering | Event payload | mitigate | Require JSON object payloads, cap payload size at 8192 bytes, and reject unsupported event types. |
| T38-08 | Repudiation | Retry and duplicate events | mitigate | Preserve `clientEventId` idempotency and return duplicate metadata. |
| T38-09 | Denial of Service | Oversized event payload | mitigate | Reject payload JSON over `MAX_EVENT_PAYLOAD_BYTES = 8192`. |
| T38-10 | Elevation of Privilege | Reward events | mitigate | Record baseline `reward_acquired` event only; do not grant arbitrary inventory or admin-controlled reward side effects from raw client payload. |
</threat_model>
