<action>
Create dependency preview logic.

Preview input:
- target type/id or code
- action
- execution mode
- optional cascade flag

Preview output must include:
- current status
- target status after action
- allowed transition flag
- `previewHash`
- grouped impact counters
- impact list grouped by type/severity
- `hasBlockingImpacts`
- Traditional Chinese labels

Impact sources:
- inbound `content_relation_links` where selected target is relation target
- outbound `content_relation_links` where selected target owns relations
- structural child relationships:
  - city -> sub_map
  - city/sub_map -> poi
  - indoor_building -> indoor_floor
  - indoor_floor -> indoor_node
  - storyline -> story_chapter
  - experience_flow -> experience_flow_step
- `exploration_elements` owner/scope references for progress impact
- content asset references where direct asset id columns or relation links are available

Severity rules:
- `remove` with published downstream children is `blocking` unless cascade is true and supported
- `unpublish` with published dependents is `warning`
- public runtime disappearance is `info` or `warning` depending on target type
- invalid transition is `blocking`

Preview hash:
- stable hash over target type/id, action, current status, impact ids/types, and timestamp bucket or current updatedAt where available
- persisted in operation records and returned to UI
</action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin request -> lifecycle service | Operators request high-impact status mutations |
| lifecycle service -> cross-domain mappers | Generic code updates many domain tables |
| scheduler/due runner -> operation records | Stored operations execute later without a live browser session |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T35-05 | Tampering | lifecycle mutation | mitigate | Validate transitions, require preview confirmation, and update target status through registry descriptors only. |
| T35-06 | Repudiation | scheduled operations | mitigate | Persist operator, reason, request JSON, preview hash, result JSON, and timestamps for every operation. |
| T35-07 | Elevation of Privilege | operation endpoints | mitigate | Keep endpoints under existing admin auth interceptor path; do not expose lifecycle APIs publicly. |
| T35-08 | Denial of Service | dependency preview | mitigate | Cap representative impact rows and return counts; avoid recursively loading full content trees. |
</threat_model>
