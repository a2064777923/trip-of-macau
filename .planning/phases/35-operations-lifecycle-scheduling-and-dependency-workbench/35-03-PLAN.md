<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator -> admin UI | Human selects high-impact lifecycle actions |
| admin UI -> admin backend | Browser submits preview/apply/schedule requests |
| preview -> confirmation | Operator must understand impacts before mutation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T35-09 | Tampering | lifecycle form | mitigate | Disable apply/schedule until preview exists and confirmation is checked; validate reason for destructive actions. |
| T35-10 | Information Disclosure | history/detail drawers | mitigate | Show operational impact metadata only, not secrets or raw provider config. |
| T35-11 | Denial of Service | repeated submissions | mitigate | Show loading state and disable buttons while preview/apply/schedule requests are in flight. |
| T35-12 | Usability risk | dependency preview | mitigate | Group impacts with Traditional Chinese labels and severity tags; avoid raw JSON-first presentation. |
</threat_model>
