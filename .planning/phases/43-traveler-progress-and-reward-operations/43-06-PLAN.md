<objective>
Add an explicit local migration apply/verify path for Phase 43 reward support schema so existing MySQL volumes receive the new grant table and redemption source/idempotency columns before smoke verification.
</objective>

<threat_model>
## Threat Model

**Assets:** local MySQL schema, reward redemptions, game reward grant table, developer environment credentials.

**Threats:**
- **T43-06-A High: false smoke failure from unapplied schema** - Docker init SQL does not run against existing volumes. Mitigation: add an explicit apply script and make smoke verify it before Phase 43 operations.
- **T43-06-B Medium: credential leakage** - Local DB password can appear in logs. Mitigation: read from env and redact password-like strings from output.
- **T43-06-C Medium: encoding corruption** - SQL contains future Traditional Chinese comments or seed text. Mitigation: read the SQL file as UTF-8 and require `SET NAMES utf8mb4;`.
</threat_model>

    <action>
      Create `scripts/local/apply-phase-43-traveler-ops-migration.ps1`.

      The script must:
      - Set `[Console]::OutputEncoding` and `$OutputEncoding` to UTF-8.
      - Accept params/switches `-SqlPath`, `-MysqlHost`, `-MysqlPort`, `-Database`, `-Username`, `-Password`, `-VerifyOnly`, and `-AllowNonLocal`.
      - Default `-SqlPath` to `scripts/local/mysql/init/52-phase-43-traveler-progress-reward-ops.sql`.
      - Default host/port/db/user/password from env vars `LOCAL_MYSQL_HOST`, `LOCAL_MYSQL_PORT`, `LOCAL_MYSQL_DATABASE`, `LOCAL_MYSQL_USERNAME`, `LOCAL_MYSQL_PASSWORD`, with local fallback values matching repo local Docker configuration.
      - Block non-local hosts unless `-AllowNonLocal` is passed.
      - Read the SQL file with `Get-Content -Encoding UTF8 -Raw`.
      - Verify the SQL contains `SET NAMES utf8mb4;` before applying.
      - Apply through `mysql.exe` when available, or Docker `docker compose exec -T mysql mysql ...` when local compose is running.
      - Make migration application idempotent by checking `information_schema` first and applying only missing schema changes:
        - Use `CREATE TABLE IF NOT EXISTS user_game_reward_grants`.
        - Add `reward_redemptions.source_event_id` only when the column is missing.
        - Add `reward_redemptions.source_rule_id` only when the column is missing.
        - Add `reward_redemptions.source_session_id` only when the column is missing.
        - Add `reward_redemptions.idempotency_key` only when the column is missing.
        - Add `uk_reward_redemptions_idempotency` only when the index is missing.
        - Add `uk_user_game_reward_grant_idempotency` only when the index is missing.
      - Seed deterministic local smoke fixtures idempotently after schema apply:
        - `game_rewards.code='phase43_smoke_game_reward'`, `reward_type='badge'`, `status='published'`, Traditional Chinese name `Phase 43 煙測徽章`.
        - `reward_rules.code='phase43_smoke_resend_rule'`, `rule_type='support_resend'`, `status='active'`, Traditional Chinese name `Phase 43 煙測補發規則`.
        - Use `INSERT ... ON DUPLICATE KEY UPDATE` or pre-checks so reruns do not duplicate fixtures.
      - Never print the password value.
      - Redact strings matching `password`, `MYSQL_ROOT_PASSWORD`, `SECRET`, and `sk-` from report output.
      - In `-VerifyOnly` mode, do not apply SQL; only query information schema.
      - In standard mode without `-VerifyOnly`, apply the migration SQL to the active local MySQL database, then run the same information schema verification before exiting.
      - Standard mode must exit nonzero if either SQL application or post-apply verification fails.

      The verification query must assert:
      - table `user_game_reward_grants` exists.
      - column `user_game_reward_grants.idempotency_key` exists.
      - unique index `uk_user_game_reward_grant_idempotency` exists.
      - column `reward_redemptions.source_event_id` exists.
      - column `reward_redemptions.source_rule_id` exists.
      - column `reward_redemptions.idempotency_key` exists.
      - unique index `uk_reward_redemptions_idempotency` exists.
      - fixture `game_rewards.code='phase43_smoke_game_reward'` exists.
      - fixture `reward_rules.code='phase43_smoke_resend_rule'` exists.
