<objective>
Upgrade the admin user progress page into a Traditional Chinese traveler progress and reward support workbench with readable filters, tabs, rule trace drawers, reward/backpack panels, and preview-first support actions.
</objective>

<threat_model>
## Threat Model

**Assets:** admin token, traveler profile, event payloads, reward state, repair preview tokens, audit records.

**Threats:**
- **T43-03-A Medium: accidental support action submission** - UI can send repair requests. Mitigation: require preview first, explicit confirmation text, non-empty reason, and disabled submit while loading.
- **T43-03-B Medium: raw sensitive payload overexposure** - Raw JSON can include user/runtime context. Mitigation: show summaries by default and move raw payloads into "查看詳情" drawer/collapse.
- **T43-03-C Medium: operator confusion from cramped filters** - Misread filters can cause wrong-user or wrong-scope actions. Mitigation: labeled filter cards, adequate select widths, current user header, and preview summary before apply.
- **T43-03-D Low: duplicate clicking creates repeated applies** - Mitigation: disable confirm buttons while requests are pending and refresh audit/timeline after completion.
</threat_model>
