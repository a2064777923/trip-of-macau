<threat_model>
## Threat Model

**Assets:** admin credentials/token, traveler support data, repair preview tokens, smoke evidence, local environment secrets.

**Threats:**
- **T43-04-A High: secret leakage in UAT reports** - Admin auth tokens and local credentials may appear in smoke logs. Mitigation: redact `Authorization`, `Bearer`, `token`, `refreshToken`, `password`, `apiKey`, `secret`, `sk-`, `COS_SECRET`, `SECRET_ID`, and `SECRET_KEY`.
- **T43-04-B Medium: accidental production mutation** - Support actions can mutate state. Mitigation: default endpoints are `127.0.0.1:8081` and `127.0.0.1:8080`; script labels non-local base URLs as BLOCKED unless `-AllowNonLocal` is passed.
- **T43-04-C Medium: false acceptance** - Automated smoke is not physical-device UAT. Mitigation: write manual WeChat checks as `PENDING` unless actually performed.
      - **T43-04-D Medium: unsafe apply during quick smoke** - Applying repair can change local test data. Mitigation: `-Quick` remains preview-only, while the standard acceptance run applies only an audit annotation with no runtime state mutation.
</threat_model>
