<behavior>
- Safe default mode runs without requiring provider/COS/admin/traveler secrets.
- Live provider/COS/auth checks run only when explicitly enabled by environment variables or command switches.
- The wrapper writes a concise Markdown report with pass, skip, fail, and blocked states.
- The wrapper exits non-zero when required safe checks fail.
- The wrapper does not print secret values or commit local absolute paths.
</behavior>
<action>
Create `scripts/local/smoke-phase-40-release-readiness.ps1`.

Implement strict UTF-8 PowerShell setup:
```powershell
$ErrorActionPreference = 'Stop'
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
```

Add parameters:
```powershell
param(
  [switch]$Quick,
  [switch]$IncludeBuilds,
  [switch]$IncludeLive,
  [switch]$IncludeAdminQaActions,
  [string]$ReportPath = ''
)
```

Resolve these environment flags as booleans:
```text
PHASE40_INCLUDE_BUILDS
PHASE40_INCLUDE_LIVE
PHASE40_INCLUDE_ADMIN_QA_ACTIONS
PHASE40_FAIL_ON_SKIPPED_LIVE
```

Default `$ReportPath` to:
```text
.planning/phases/40-acceptance-cost-visibility-and-release-readiness/40-SMOKE-REPORT.md
```

Add helpers:
- `Get-EnvFlag($Name)` returning `$true` for `1`, `true`, `yes`, or `on`.
- `Add-Result($Area, $Check, $Status, $Evidence, $Command = '')` where `$Status` is exactly one of `PASS`, `SKIP`, `FAIL`, `BLOCKED`.
- `Invoke-CheckedCommand($Area, $Check, $Command, $WorkingDirectory = $ProjectRoot, $AllowSkip = $false)` using `System.Diagnostics.ProcessStartInfo` so stdout/stderr can be captured.
- `Assert-NoSecretText($Text, $Context)` rejecting these exact case-insensitive patterns: `sk-`, `Bearer `, `COS_SECRET`, `SECRET_ID`, `SECRET_KEY`, `providerApiKey`, `apiKey`, `authorization`, `promptText`, `scriptText`, `localPath`.
- `Write-Report()` that writes `# Phase 40 Smoke Report`, timestamp, mode flags, a result table, skipped live dependency notes, and final outcome.

Required checks:
1. `planning artifacts`: assert these files exist: `40-CONTEXT.md`, `40-RESEARCH.md`, `36-VERIFICATION.md`, `38-VERIFICATION.md`, `39-VERIFICATION.md`.
2. `Phase 36 material production`: run `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/local/smoke-phase-36-material-production.ps1 -ValidateOnly` in default/quick mode.
3. `Phase 36 live material/COS`: run `scripts/local/smoke-phase-36-material-production.ps1 -IncludeVideo -RunProduction` only when `$IncludeLive` or `PHASE40_INCLUDE_LIVE` is true; otherwise record `SKIP` with evidence `set PHASE40_INCLUDE_LIVE=true to enable provider/COS live checks`.
4. `Phase 37 material QA`: run `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/local/smoke-phase-37-material-qa.ps1 -SkipActions` unless admin login is unavailable; if unavailable, record `BLOCKED` not `PASS`.
5. `Phase 37 QA actions`: run without `-SkipActions` only when `$IncludeAdminQaActions` or `PHASE40_INCLUDE_ADMIN_QA_ACTIONS` is true; otherwise record `SKIP`.
6. `Phase 38 public runtime assets`: run `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/local/smoke-phase-38-public-runtime-assets.ps1`.
7. `Phase 39 story mode smoke`: run `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/local/smoke-phase-39-mini-program-story-mode.ps1`.
8. `Client story-mode alias`: run `npm run smoke:phase39:story-mode` from `packages/client`.
9. `Mini-program build`: run `npm run build:weapp` from `packages/client` when `$IncludeBuilds`, `PHASE40_INCLUDE_BUILDS`, or non-`Quick` mode is active. In `Quick` mode without include flag, record `SKIP`.
10. `Admin UI build`: run `npm run build` from `packages/admin/aoxiaoyou-admin-ui` only when `$IncludeBuilds` or `PHASE40_INCLUDE_BUILDS` is true; otherwise record `SKIP`.
11. `Public backend compile`: run `mvn -q -DskipTests compile -f packages/server/pom.xml` when `$IncludeBuilds` or `PHASE40_INCLUDE_BUILDS` is true; otherwise record `SKIP`.
12. `Admin backend compile`: run `mvn -q -DskipTests compile -f packages/admin/aoxiaoyou-admin-backend/pom.xml` when `$IncludeBuilds` or `PHASE40_INCLUDE_BUILDS` is true; otherwise record `SKIP`.

Failure rules:
- Any `FAIL` result exits `1`.
- Any `BLOCKED` result exits `1` unless it is a live-only check and `PHASE40_FAIL_ON_SKIPPED_LIVE` is false.
- `SKIP` is allowed only with an evidence string that explains the env/config needed.
- Before writing report and before printing captured command output, run `Assert-NoSecretText`.

Final success line:
```text
Phase 40 release-readiness smoke completed.
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| local shell -> backend services | Smoke commands call admin/public services and may use local env credentials. |
| smoke wrapper -> child phase scripts | Phase 40 composes scripts that may have different failure/skip behaviors. |
| captured output -> planning report | Smoke output becomes committed evidence and must be sanitized. |
| client npm alias -> repository scripts | Operators may run smoke from a package directory instead of repo root. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- |
| T40-01 | Information Disclosure | smoke output | mitigate | Reject banned secret-bearing strings before printing or writing report. |
| T40-02 | Repudiation | smoke report | mitigate | Record command name, status, evidence, timestamp, and skip reason per check. |
| T40-03 | Tampering | live smoke branches | mitigate | Gate live provider/COS/admin QA actions behind `PHASE40_INCLUDE_LIVE` and `PHASE40_INCLUDE_ADMIN_QA_ACTIONS`. |
| T40-04 | Denial of Service | build-heavy checks | mitigate | Provide `-Quick` and `PHASE40_INCLUDE_BUILDS` so expensive checks are explicit. |
| T40-05 | Spoofing | child smoke auth | mitigate | Reuse existing dev-bypass env gating; do not silently create auth identities in Phase 40 wrapper. |
</threat_model>
