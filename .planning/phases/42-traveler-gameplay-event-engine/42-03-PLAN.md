<threat_model>
## Threat Model

**Assets:** local auth token, public backend data, story event smoke evidence, UAT docs, workstation paths.

**Threats:**
- **T42-03-A Medium: secret leakage in reports** - Smoke scripts may handle bearer tokens. Mitigation: redact `sk-`, `Bearer`, `apiKey`, `secret`, `Authorization`, and raw token values from report rows.
- **T42-03-B Medium: false acceptance** - Automated smoke cannot prove real GPS, AR, speech, or physical-device UI. Mitigation: write `SKIP`/`PENDING` for manual-only checks unless actually performed.
- **T42-03-C Low: accidental production writes** - Smoke should target local/dev only. Mitigation: default base URL is `http://127.0.0.1:8080/api/v1`, default dev identity is ASCII, and docs state experience/prod must use real WeChat auth.
</threat_model>
